# SelPad
SelPad is a macropad project for hack club.(my first kinda). Its used to select text and work alongside a normal keyboard ,and its functions. My main purpose for creating this is that my current keyboard is rather laggy and the mousepad is even worse.Therefore this project adds to my learning while also being useful in everyday life.
